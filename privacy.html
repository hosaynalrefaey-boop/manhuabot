Privacy Policy

Last updated: November 22, 2026 · Application: Manhua Bot

1. Overview

Manhua Bot is a personal, self-hosted automation tool. This Privacy Policy explains what Google user data the application accesses, how it is used, and how it is handled.

2. Google User Data Accessed

When authorized by the account owner, Manhua Bot uses the Google Drive API (https://www.googleapis.com/auth/drive) solely to:

  • Create and locate dedicated upload folders inside the owner's Google Drive.
  • Upload image files requested by the owner.
  • Set sharing permissions on those uploaded folders when requested.

3. How Data Is Used and Stored

Google Drive access is used strictly to perform the upload actions initiated by the owner. The application does not sell, share, transfer, or disclose any Google user data to third parties, and does not use Google user data for advertising or analytics. OAuth credentials and refresh tokens are stored privately on the owner's self-hosted server.

4. Google API Services User Data Policy

Manhua Bot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy , including the Limited Use requirements.

5. Revoking Access

You can revoke the application's access to your Google account at any time from your Google Account Permissions page.
